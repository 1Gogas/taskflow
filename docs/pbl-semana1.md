
# PBL — Semana 1: Versionamento

## Situação-problema

O TaskFlow é uma API REST desenvolvida em Python
com FastAPI para gerenciamento de tarefas.

O projeto inicial não possui automação de processos.
Durante as próximas semanas, a equipe deverá
evoluir o projeto utilizando práticas de DevOps.

## Problema identificado

A equipe precisa organizar o código-fonte, controlar
as alterações feitas por cada integrante e documentar
o processo de desenvolvimento para facilitar a
colaboração e a manutenção do sistema.

## Objetivos da semana

- Criar um fork do repositório original.
- Configurar o controle de versão com Git.
- Criar um arquivo .gitignore.
- Executar a API localmente.
- Documentar o projeto no README.md.
- Registrar alterações usando Conventional Commits.
- Criar a tag v0.1.

## Resultado esperado

Um repositório próprio no GitHub, com documentação,
arquivos organizados e histórico de commits dos dois
integrantes, preparado para as próximas etapas do
projeto DevOps.
